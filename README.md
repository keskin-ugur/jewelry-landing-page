# Hazinedaroğlu Kuyumculuk — Jewelry Landing Page

**Live:** [hazinedaroglu.netlify.app](https://hazinedaroglu.netlify.app)

A luxury coming soon / pre-launch website built for a local jewelry store in Turkey. The focus was on creating a high-end visual experience with smooth animations, full-screen video sections, and a minimal editorial aesthetic.

## ✨ Features

- Full-screen autoplay video backgrounds per product category (jewelry, gold, watches) — generated with Runway AI
- Scroll-triggered fade-up animations via Intersection Observer
- Sticky nav with blur backdrop on scroll
- Responsive mobile menu
- Contact form UI
- Gold accent color system (`#C9A84C`) with custom Tailwind utilities
- Playfair Display serif + Inter sans-serif type pairing

## 🛠️ Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open localhost:3000
